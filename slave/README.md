# HUBUS Slave Library

Interrupt-driven HUBUS slave for tinyAVR microcontrollers: the public API (`hubus_slave.h`), the build options (`hubus_slave_config.h`), and one hardware abstraction layer per device family (`hal/`). The protocol logic is in `../core/`.

Documentation: [slave library](../docs/slave-library.md) (API, optional parts, configuration, supported devices, footprint, examples) and the slave requirements of the specification ([§7](../docs/spec/07-slave.md)).
